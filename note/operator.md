# 运算符重载（operator）知识点

## 一、基本概念

运算符重载 = 让自定义类型支持内置运算符（`+` `<` `()` 等）。

```cpp
返回类型 operator符号(参数列表) { ... }
```

**两条铁律**：
1. 至少一个操作数是自定义类型
2. 不能改变运算符优先级、结合性、操作数个数，不能发明新符号

## 二、成员函数 vs 友元函数

```cpp
// ① 成员形式：隐式 this 是左操作数
A operator+(const A& o) const { return {val + o.val}; }

// ② 友元形式：左右操作数显式写出，可访问私有成员
friend A operator+(const A& a, const A& o) { return {a.val + o.val}; }
```

| 运算符 | 要求 | 说明 |
|--------|------|------|
| `=` `[]` `()` `->` | 必须成员 | C++ 强制 |
| `<<` `>>`（流） | 必须友元 | 左操作数是流对象 |
| 类型转换 `operator T()` | 必须成员 | 只能是成员 |
| 算术/关系/复合赋值 | 二选一 | 想支持 `int + A` 隐式转换用友元 |

## 三、各类运算符速查

| 类别 | 写法要点 |
|------|---------|
| 算术 `+ - * / %` | 返回新对象（值），`const` |
| 关系 `< > ==` | 重载 `<` 即可用于 sort/set/map/pq |
| 赋值 `=` | 返回 `*this` 引用（链式）；自赋值检查 `if(this != &o)` |
| 下标 `[]` | 写 `int&`，读 `const int&` |
| 调用 `()` ★ | 仿函数，供容器/算法传比较规则 |
| 自增 `++ --` | 前缀返回引用；后缀加占位 `(int)` 返回旧值 |
| 流 `<< >>` | 友元，返回流引用 |
| 复合 `+= -=` | 返回 `*this` 引用 |
| 类型转换 | 建议 `explicit` |
| 一元 `-` | 返回新对象 |

## 四、重点：仿函数 `operator()`

```cpp
struct Cmp {
    bool operator()(int a, int b) const { return a > b; }   // 小顶堆
};
priority_queue<int, vector<int>, Cmp> pq;   // 当第三个模板参数用
```

## 五、重点：关系运算符 `<`（用于 sort / priority_queue）

```cpp
struct Point {
    int x, y;
    bool operator<(const Point& o) const {
        return x == o.x ? y < o.y : x < o.x;
    }
};
```

> 注意：`priority_queue` 靠 `<` 决定优先级，`sort` 升序也靠 `<`，方向要按容器想清楚。

## 六、不能重载的运算符

`.`（成员访问）、`::`（作用域）、`.*`、`?:`（三目）、`sizeof`、`#`/`##`

## 七、常见坑

1. 比较器方向写反 → 堆/排序结果反转
2. `=` 忘自赋值检查 → double-free
3. `++` 前后缀忘区分 → 后缀加占位 `(int)`
4. `<<` 用成员实现 → 编译错误
5. `operator()` 忘 `const`、参数忘 `const&`
6. 比较器不满足严格弱序 → 容器行为未定义
